## 📌 About the Project

AeroBMSCE is a frontend website redesign project undertaken as part of a web development recruitment task. The objective was to improve the original website's visual presentation, usability, consistency, and overall browsing experience while retaining the identity, history, and achievements of the club.

The redesign focuses on creating a visually appealing experience that presents the club's journey, work, accomplishments, and partnership opportunities in a clear and engaging way.

## 🎯 Website Sections

- **Home** — Introduces the club through an engaging landing page.
- **Who We Are** — Presents the club's identity, background, and journey.
- **What We Build** — Highlights the club's technical work and projects.
- **Achievements** — Showcases the club's milestones and accomplishments.
- **Partner With Us** — Provides a section for collaborations and partnerships.

## 🛠️ Tech Stack

- **HTML5** — Semantic structure and page content.
- **CSS3** — Layout, visual styling, transitions, and animations.
- **JavaScript** — Interactive elements and dynamic behavior.
- **Git & GitHub** — Version control and project hosting.
- **GitHub Pages** — Live website deployment.

## 🔍 1. Flaws in the Original Website

During the initial review, the objective was to identify areas where the original website could be improved, including:

- **Visual consistency:** Improving consistency across typography, spacing, colors, and components.
- **Layout and presentation:** Making content easier to scan and improving the overall visual hierarchy.
- **Navigation and usability:** Reviewing links and navigation elements to provide a clearer browsing experience.
- **Image presentation:** Improving the placement, sizing, and integration of images.
- **User engagement:** Making the interface more visually interesting through improved design and appropriate interactive elements.

These observations guided the redesign, with the goal of presenting information more clearly without losing the club's original identity.

## 🎨 2. Design Approach and UI/UX Decisions

My design approach focused on combining visual impact with clarity and usability.

- **Clear visual hierarchy:** Important information and section headings are given prominence so visitors can understand the content quickly.
- **Consistent design system:** Typography, spacing, colors, and interface elements are used consistently throughout the website.
- **Visual storytelling:** Images are used to support the content and make the club's journey and work more engaging.
- **Animations and interactions:** Motion and interactive elements are used to add depth and improve engagement without making the interface unnecessarily distracting.
- **Structured navigation:** The content is organized into dedicated sections so visitors can explore the club's identity, projects, achievements, and partnerships.
- **Preserving the club's identity:** The redesign aims to retain the club's history and achievements while presenting them through a refreshed interface.
- **Responsive considerations:** The layout is designed with adaptability and consistent presentation across different screen sizes in mind.

The overall goal was to create an experience that feels modern and memorable while remaining easy to navigate.
